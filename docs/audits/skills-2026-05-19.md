## Highest-value skills (saves 3× their load cost or more)

These are the load-bearing ones. If forced to cut the catalog, keep these:

1. **`equipment`** — ~19k tokens saved per use. Covers 5+ files with
   complex invariants (id unions, `WEAPON_IDS` `satisfies` guard, family
   gating, BootScene generators, loot pool wiring). An agent doing this
   from scratch routinely misses the satisfies guard or family gating
   and ships a typecheck-clean bug.
2. **`save-roundtrip-audit`** — ~18k tokens saved. The 8-layer round-trip
   is exactly the bug class behind the 2026-05-02 wipe. Skill captures
   layers an agent reading code would miss (POST upsert conflict
   columns, sync.ts threading, hydrate consumer).
3. **`new-migration`** — ~9k tokens saved. Captures CLAUDE.md §7a HARD
   RULE (migration MUST be applied to prod). Without the skill, agents
   skip the apply step and the next save POST 500s. Pinned recurrence
   of an actual incident.
4. **`ai-codegen-smell-audit`** — ~8k tokens saved. 10 concrete checks
   tied to specific failure modes; calibration scheme + sidecar
   dismissal protocol are hard to recreate ad-hoc.
5. **`security-audit`** — ~8k tokens saved (mostly coordination). Phase
   orchestration is the value: knowing which agent runs which phase and
   what artifact gates each transition.

## Methodology notes

- "Replacement cost" estimates the cost of a competent agent
  rediscovering the skill's contents from the codebase: grep for
  relevant files, read each, infer the invariants. It does NOT
  include the cost of retry loops triggered by a missed convention
  (where the real win lives) — so the savings numbers are conservative.
- "Frequency" is judged from recent session history and the type of
  task each skill addresses, not from telemetry (none available).
- Verdicts use a load-cost vs. replacement-cost ratio. >2× is "keep"
  by default; <2× requires a non-token justification (e.g. error
  prevention, convention enforcement). Only `new-weapon` falls below
  2× and is kept on convention-stub grounds.
